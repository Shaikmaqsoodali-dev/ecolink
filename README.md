# Ecolink India — Website

A complete, multi-page marketing website for **Ecolink India** (a brand of Deluxe Recycling (India) Pvt. Ltd.), built from the approved copy deck with a premium industrial editorial look inspired by the Manufact reference.

## Quick start

```powershell
node build.mjs          # regenerate all 15 HTML pages from src/
node tools\serve.mjs    # local preview at http://localhost:4173
node tools\fonts.mjs    # re-download the self-hosted fonts (rarely needed)
node tools\linkcheck.mjs # verify every internal link and asset resolves
```

No npm install, no dependencies — plain Node (ESM) + static HTML/CSS/JS.

### Environment variables

| Variable | Purpose |
|---|---|
| `FORM_ENDPOINT` | URL that receives the contact form as JSON `POST`. When unset, the form shows an honest "not connected yet" notice and never fakes a success. |

```powershell
$env:FORM_ENDPOINT = "https://example.com/api/enquiry"
node build.mjs        # bakes the endpoint into contact/index.html
```

## Structure

```
build.mjs             page generator (entry point) + sitemap/robots/favicon
src/
  data.mjs            all approved copy-deck content — single source of truth
  layout.mjs          HTML shell (canonical, OG, Twitter, JSON-LD, fonts, preload)
  ui.mjs              reusable components (header, drawer, footer, hero, cards, form…)
  pages/*.mjs         one module per page
assets/
  css/style.css       design system + components + responsive + reduced-motion
  css/fonts.css       @font-face for the self-hosted fonts
  fonts/*.woff2       Manrope (headings) + Inter (body), latin subsets, OFL
  img/                photography, product shots, generated world.svg
  img/logo-deluxe.png client logo (header, footer, favicon)
  favicon.svg         generated from the client logo at build time
  js/main.js          sticky header, drawer, dropdown, reveals, split headlines,
                      image zoom-on-scroll (viewport-centre easing, disabled
                      under prefers-reduced-motion),
                      counters (Indian digit grouping), accordion, form
                      (endpoint POST, loading, duplicate guard, error states),
                      cookie consent gating analytics, back-to-top, topic pre-fill
tools/
  serve.mjs           local static server (port 4173), directory routes + 404
  fonts.mjs           downloads Manrope/Inter woff2 and writes fonts.css
  worldmap.mjs        generates assets/img/world.svg + pin projections
  linkcheck.mjs       checks every href/src in the built HTML
```

## Brand

- **Logo:** `assets/img/logo-deluxe.png` (supplied by the client). Used in the
  header, footer and generated favicon. Replace this one file to update it everywhere.
- **Palette:** charcoal `#171A18` · forest `#244B37` · green `#477A4F` ·
  lime `#B6D76A` · off-white `#F5F5F0` · white `#FFFFFF` · grey `#E8EAE5` ·
  body `#555D56`.
- **Type:** Manrope (headings) + Inter (body), self-hosted for performance,
  `clamp()` scaling throughout.
- **Header:** transparent over the home hero, solid (blurred) on scroll; dark
  text on light page heroes; mobile drawer with nested product links.
- **Naming:** the site brand is *Ecolink India*; the legal entity *Deluxe Recycling
  (India) Pvt. Ltd.* appears in the footer and copyright, exactly as in the copy deck.

## Content rules

Everything on the site comes from the approved copy deck (`copydeck.txt` is the
extracted text). No testimonials, client logos, certifications, load capacities,
leadership bios, addresses or environmental claims were invented — unverified
items are either omitted or flagged in the markup with `pending` / "to be
confirmed" notes.

- Ecolink Boards are described as **water resistant**; Ecoshakti and ESS Boards
  as **100% waterproof**. This distinction is preserved everywhere.

## Open items for the client (do not invent answers)

1. **Contact details** — phone, email mailbox, factory address and hours are
   placeholders flagged `[to confirm]`.
2. **Form backend** — set `FORM_ENDPOINT` before launch; until then the form
   honestly reports that it is not connected.
3. **Specs to confirm:** board sizes/thicknesses, roofing profile/colours, door
   types/sizes, pallet load capacity, ISPM-15 status.
4. **Claims to confirm:** per-board waste diversion figures, third-party
   environmental verification, certifications (not displayed until supplied).
5. **FAQ answers** marked `pending` (5 of 12): sizes, cutting/painting, waste
   per board, delivery, certifications.
6. **Assets to supply:** plant walkthrough video, customer/partner logos for the
   "Trusted by" strip, testimonial quotes (section hidden until supplied),
   brochures/spec sheets (downloads block hidden until supplied), social URLs.
7. **Analytics** — wire the real provider in `loadAnalytics()` in `assets/js/main.js`;
   it only fires after the visitor accepts cookies.

## Quality checks run

- **Build:** 15 pages + sitemap.xml + robots.txt + favicon generated cleanly.
- **Links:** `tools/linkcheck.mjs` — zero missing assets or internal links.
- **Routes:** all 15 URLs load with correct `<title>`, single `<h1>`, canonical
  URL, meta description, footer and zero console errors (404 page intentionally
  logs its own 404).
- **Interactions:** Products dropdown (click + Escape + focus return), mobile
  drawer (open/close + body scroll lock), FAQ accordion (12 items), counters,
  back-to-top, cookie consent (persists and gates analytics), `?topic=` prefill.
- **Form:** validation errors shown per field; unconnected state never fakes
  success; with `FORM_ENDPOINT` set, a real JSON POST succeeds (verified against
  a local mock — one request per double-submit, success + form reset); error
  path shows a recoverable error message and re-enables the button.
